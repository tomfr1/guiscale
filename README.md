# GUI Scale Plus (Fabric, 1.21.11)
Eigene GUI-Größe pro Menütyp: Inventar, Container (Kisten, Öfen, Handel ...), andere Menüs.
HUD/Hotbar bleibt bei der Größe aus den Videoeinstellungen.

Menü: Taste K (änderbar unter Steuerung). Config: config/guiscaleplus.json

Build: `gradle build` (Gradle 8.14+, Java 21) -> build/libs/guiscaleplus-1.0.0.jar
